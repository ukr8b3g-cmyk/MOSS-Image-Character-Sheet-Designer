## Editable MOSS view prompts

- New **Prompts** tab after Settings: edit any of the 13 view instructions, Apply, or Reset this prompt.
- Per-node workflow persistence, including intentional blanks; edits survive feature analysis in Layout JSON and Caption output.
- Existing workflow, node names (including v1.0), input/output sockets, model settings and unedited defaults are preserved. Package version is 1.0.1.
- English/Japanese instructions distinguish base prompt replacement from additive Part prompts.

### Validation and remaining limits

Python24 and JavaScript/DOM9 pass. Local Chrome save/reload and the live preview API were checked. Controlled feature JSON covers post-analysis preservation, including empty outfit facts. No new encoder/GPU quality benchmark was run. Repeated or missing views, garment/body fragments and image-description information loss remain possible. The preview does not show the final runtime prompt. Windows IME and Nodes 2.0 remain unverified.

Image input still becomes a text description followed by new T2I generation; it is not direct image editing. Per-view instructions are limited to 2,000 UTF-16 units. Keep an edited workflow copy before opening it with an older extension version.

### Downloads / 更新

Use the extension ZIP, or update the repository, restart ComfyUI and reload the browser. The attached v1.0 workflow is unchanged and works with 1.0.1; no rewiring is needed. Model weights are not included. Checksums are provided in SHA256SUMS.txt.
